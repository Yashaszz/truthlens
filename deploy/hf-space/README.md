# TruthLens

Multimodal digital forensics: AI-generated images, face-swap deepfakes, cloned voices and misleading captions,
with calibrated verdicts, a per-threat matrix and an explainable forensic report.

This Space is the always-on CPU backup of the main GPU deployment, so analyses are slower here.
Source and evaluation: https://github.com/Yashaszz/truthlens
